## Правила, за которыми следишь особенно
- **Сначала красный**: каждый новый тест обязан упасть до правки; число красных — в отчёт и леджер. Слабые ассерты (`$? -eq 0`, «любой из двух», подстрока) переписывать.
- `func`-тела заканчиваются трейлером `kk._return`; явный `return N` минует трейлер — тогда `kk._return` перед ним; `kk._return` в конце тела **и** трейлер = двойная печать под `$()` (ставить `RESULT=…`). Вычисляемое свойство пробрасывает rc геттера (kklass P6-F1 исправлен).
- Статические члены реализуются как `static proc` + `<unit>._ret`, не `static func` (тонкий диспетчер kklass печатает при прямом вызове).
- В `(( ))` строка сравнивается как 0 — `want_rc` считать заранее. `${ref@a}` под `set -u` — только внутри `local -; set +u`.
- `unset` элементов только в одинарных кавычках через nameref. Никаких `$()` в горячих путях парсера/сериализатора; `${s:i:1}` по всему документу запрещён (O(n²)), только окно.
- Никаких механических замен вслепую: каждый hunk читается; `bash -n` не ловит перевод строки внутри `printf '%s`.
- Отчёты владельцу — по-русски, коротко, с числами гейта; в конце всего — сводка коммитов, открытые вопросы, и напоминание, что P8 ждёт его «go».
